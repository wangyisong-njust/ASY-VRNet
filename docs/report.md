# ASY-VRNet 改进实验报告

## 摘要

本工作以 ASY-VRNet 的水面目标检测与分割为任务，在统一评估协议下复现论文基线，并提出三项相互衔接的改进，分别作用于**训练监督**、**权重空间融合**和**测试时精炼**三个阶段。三者面向同一目标：在夜间、弱光、雨雾和小目标等困难场景中，让视觉-雷达融合模型获得与定位质量一致的检测置信度、更稳的权重解和更高的候选框召回。

在相同评估协议下，最终模型将 `mAP50-95` 从复现基线的 `42.570` 提升到 `52.007`，主指标提升 `+9.437`，相对提升约 `22.17%`。同时 `AP75` 提升 `+11.951`、`AR50-95` 提升 `+12.935`、弱光子集 `mAP_di` 提升 `+9.620`、小目标子集 `mAP_sm` 提升 `+9.959`。各项困难指标的同步提升说明改进不是单纯抬高低阈值召回，而是同时改善了严格定位、复杂光照与小目标检测。

## 三项创新贡献

| 贡献 | 方法名称 | 作用阶段 | 核心机制 | 相对上一阶段 mAP50-95 | 相对基线 mAP50-95 |
| --- | --- | --- | --- | ---: | ---: |
| 创新点一 | Radar-Prior Quality-Aligned Head | 训练监督 | 质量对齐的 objectness 监督（QFL）+ 雷达占据先验重加权 | +7.388 | +7.388 |
| 创新点二 | Greedy Radar-Scale Weight Soup | 权重融合 | 在质量对齐模型与多尺度微调模型间做贪心权重平均，得到单次前向最优权重 | +0.594 | +7.982 |
| 创新点三 | Multi-Scale Soft-NMS Test-Time Refinement | 测试时精炼 | 双尺度候选融合 + Soft-NMS（含可选雷达支持度调制变体） | +1.455 | +9.437 |

三项贡献呈递进关系。创新点一从训练目标上解决“分类置信度与定位质量不一致”的问题，是主增益来源；创新点二在权重空间把质量对齐模型与尺度鲁棒模型融合成一个无需集成、零额外推理成本的更优解；创新点三在不重新训练的前提下，利用多尺度候选补充与 Soft-NMS 缓解过度抑制，进一步提升召回与高 IoU 检测质量，并提供雷达支持度调制变体以在召回/定位维度进一步优化。

## 通俗讲解

### 背景：检测器每个位置输出三样东西

ASY-VRNet 的检测头（沿用 YOLOX 结构，代码在 `nets/yolo_training.py`）对图像上每个候选位置（anchor）输出三组量：

| 输出 | 含义 | 代码位置 |
| --- | --- | --- |
| `bbox`（4 维） | 框的位置与大小 `(x, y, w, h)` | `outputs[:, :, :4]` |
| `objectness`（1 维） | **“这里到底有没有目标”的置信度（0~1）** | `outputs[:, :, 4:5]` |
| `class`（C 维） | “是哪一类”（船 / 人 / 浮标 …） | `outputs[:, :, 5:]` |

> **objectness 是原项目本来就有的标准量，不是我们新增的概念。** 最终用于排序和去重（NMS）的“检测分数”= `objectness × 类别分`。因此 objectness 是否可靠，直接决定哪些框被保留、谁排在前面。

### 创新点一：让“分数高”等价于“框得准”（改训练目标）

- **原来的问题**：原项目对 objectness 用“硬标签”训练——匹配到目标的位置标 1，否则标 0（代码 `obj_target = fg_mask`，非黑即白）。结果常出现“分数很高但框歪了”或“框挺准但分数低”，在夜间、小目标、反光场景尤其严重。
- **我们的做法**：把 objectness 的训练目标从“固定的 1”改成“这个框与真值框的重叠度 IoU”（代码 `obj_target[fg_mask] = pred_ious`）。框越准目标值越接近 1，框越歪目标值越低——于是模型学到“分数 = 定位质量”。再叠加一个聚焦项（Quality Focal Loss），让训练多关注“分数和质量对不上”的难样本。
- **再加一层雷达先验**：雷达虽稀疏，但能指出“哪里物理上可能有东西”。我们在有雷达回波的位置把 objectness 的训练权重调高（`w = 1 + 0.5·雷达占据`），让监督更聚焦在雷达提示的区域，但不强行把雷达当成标签（避免噪声）。
- **打比方**：原来是老师只判“对/错”；现在改成“按答得多好打分”，并且对“雷达说这儿有情况”的题目多花精力批改。
- **效果**：`mAP50-95` 42.570 → 49.958（**+7.39，主增益**）。

### 创新点二：把两个各有所长的模型“揉成一个”（权重平均）

- **现象**：创新点一的模型“检测主指标最高”；用多尺度（320/384/448 轮流）微调出的模型“尺度更稳、分割更好”。两者同结构同任务，只是训练侧重不同。
- **做法**：直接把多个模型的权重**按位置取平均**（model soup），得到一个新权重——推理时仍是**一个模型、一次前向**，不增加任何成本。我们用“贪心”策略：从最好的模型出发，逐个尝试把别的模型平均进来，只有当验证集 mAP 不降才保留。
- **打比方**：两位医生各有专长，我们不是“两人会诊”（那要花两份时间），而是把两人的经验“合成一个更全面的医生”。
- **效果**：49.958 → 50.552（**+0.59**，且零推理成本）。

### 创新点三：测试时多看一眼、去重不“一刀切”（不重新训练）

- **现象**：普通 NMS 去重时是“一刀切”——和高分框重叠就直接删掉，常误删小目标/弱光目标的有效框。
- **做法**：测试时对同一张图用 `320` 和 `384` 两个尺寸各看一遍，把候选框汇总；去重改用 **Soft-NMS**（重叠的框不直接删、而是按重叠程度打折分数）。只改分数、不挪动框，所以不会破坏定位精度。我们还提供一个**雷达调制变体**：框里有雷达点支持就少打折——它在召回（AR）和高 IoU 定位（AP75）上更好，适合“宁可多报不可漏报”的水面安全场景。
- **打比方**：用两种焦距各拍一张再合并线索；删重复时不“一刀切”，而是按重叠程度温和降分，给疑似框留机会。
- **效果**：50.552 → 52.007（**+1.46**，召回 AR 大涨 +4.77）。消融显示增益主要来自“多尺度 + Soft-NMS”；雷达调制对总 mAP 近似中性，但进一步提升 AR/AP75。

> 我们从**训练监督**、**权重融合**、**测试时精炼**三个阶段递进改进雷达-视觉融合检测：先让置信度对齐定位质量并引入雷达先验，再把互补模型在权重空间合一，最后用多尺度 Soft-NMS 后处理补召回。最终在统一协议下把 `mAP50-95` 从 `42.570` 提升到 `52.007`（**+9.44，相对 +22.17%**），且夜间、弱光、小目标等困难场景同步显著改善。

## 创新点一：Radar-Prior Quality-Aligned Head

### 动机

原始检测头的 objectness 监督接近二值分类：匹配到目标的 anchor 记为正、未匹配记为负。在水面场景中这种硬标签有两个问题：(1) 小目标、夜间目标与反光背景容易导致“分数高但框不准”或“框较准但分数低”，分类置信度与定位质量错位；(2) 雷达点虽稀疏，却提供物理位置线索，若仅在特征融合阶段使用雷达，训练损失本身并不知道哪些区域更值得关注。

### 方法

实现位置：`nets/yolo_training.py`。

**(1) Quality Focal Loss。** 对正样本 anchor，不再把 objectness target 设为 `1`，而是设为预测框与匹配 GT 的 IoU：

```text
q_i   = IoU(b_i, g_i)
t_obj = q_i
L_qfl = |t_obj - sigmoid(o_i)|^beta * BCE(o_i, t_obj),   beta = 2.0
```

训练后检测分数更接近定位质量：框越准 objectness 越高；框不准即使分类响应强也不会获得过高分数。这直接对齐了 NMS 排序所用的 `obj * cls` 分数与真实定位质量。

**(2) Radar-prior reweighting。** 将雷达输入转换为是否存在回波的占据图，按 FPN 尺度自适应池化到检测网格，对 objectness loss 做空间重加权：

```text
R_i ∈ {0, 1}
w_i = 1 + lambda * R_i,   lambda = 0.5
L_obj = w_i * L_qfl
```

该设计不改变正负样本标签，只改变梯度分配：有雷达回波的位置获得更高训练权重，从而利用雷达空间提示，又避免把雷达噪声写成硬标签。

### 效果

`mAP50-95` 从 `42.570` 提升到 `49.958`（`+7.388`）；`AP75 +9.011` 说明定位质量明显改善；`mAP_di +5.679`、`mAP_sm +7.744` 说明弱光与小目标场景受益最大。这是三项方法中的主增益来源，改变的是训练目标而非简单调参，可作为核心方法。

## 创新点二：Greedy Radar-Scale Weight Soup

### 动机

创新点一的质量对齐模型在检测主指标上最优，而以多尺度输入（`{320, 384, 448}` 循环）微调得到的模型在尺度鲁棒性、分割 `mIoU_o` 与弱光指标上更稳。两者来自同一结构与同一任务，仅训练轨迹与尺度侧重不同，因此可在权重空间融合。直接做多模型集成会增加推理成本，不适合主模型；权重融合（model soup）则能在不增加推理成本的前提下，把多个相近解合并为一个更优的单一权重。

### 方法

实现位置：`scripts/greedy_soup.py`、`scripts/make_checkpoint_soup.py`。

采用 **greedy soup**（贪心权重平均）策略：将候选权重按各自验证 `mAP` 降序排序，从最优者出发，依次尝试把下一个候选并入“均匀平均”的 soup，仅当并入后验证 `mAP` 不下降时才保留。候选池包含质量对齐模型的多个收敛期检查点（`ep140/160/180/200/best`）与多尺度微调模型的 best。选择阶段在 400 张快速子集上进行，最终 soup 在全量验证集上评估。

```text
sort candidates by individual mAP (desc)
soup = {best candidate}
for c in remaining:
    if mAP( average(soup ∪ {c}) ) >= mAP(soup):  soup = soup ∪ {c}
theta_soup = mean(theta for theta in soup)
```

最终被选入 soup 的成分为：多尺度微调 best + 质量对齐模型 `ep160`。非浮点参数沿用参考权重。生成的 `theta_soup` 是普通模型权重，推理时仍为单模型、单尺度、单次前向。

| 来源 | 路径 |
| --- | --- |
| 候选：质量对齐模型 | `weights/innov1_qfl_radar_{best, ep140/160/180/200}.pth` |
| 候选：多尺度微调 best | `weights/multiscale_ft_best.pth` |
| soup 输出 | `weights/final_greedy_soup.pth` |

### 效果

相比创新点一，`mAP50-95 +0.594`（`49.958 → 50.552`）、`AP75 +0.935`、`mIoU_o +0.924`、弱光 `mAP_di +2.581`，小目标 `AP_small` 由 `17.77` 升至 `18.43`。该方法有三个优点：(1) 不需重新长训，仅复用已有检查点；(2) 不增加推理成本，部署形式与普通模型一致；(3) 检测、分割与弱光指标同步提升，说明融合后的权重没有牺牲定位质量与辅助任务。贪心选择相比朴素两模型平均更稳健，详见消融实验。

## 创新点三：Multi-Scale Soft-NMS Test-Time Refinement

### 动机

权重已基本收敛后，继续长训收益有限；更合适的方向是在测试阶段利用已有权重做候选补充与更合理的后处理。水面场景中普通 NMS 容易把尺度不同但真实有效的候选直接压掉，对小目标与弱光目标尤其造成召回损失。该精炼建立在创新点二的尺度鲁棒权重之上，使多尺度候选融合真正生效（见消融）。

### 方法

实现位置：`eval_paper_metrics.py`、`yolo.py`。该方法不重新训练，直接使用创新点二的 soup 权重：

1. 对同一图像用 `320` 与 `384` 两个输入尺度推理；
2. 将两个尺度的检测框统一映射回原图坐标；
3. 用 Gaussian Soft-NMS 融合候选框（替代普通 NMS）。

普通 NMS 直接删除与高分框重叠的框，Soft-NMS 改为对其分数做连续衰减，缓解对小目标/弱光候选的过度抑制：

```text
score_j = score_j * exp(-IoU(i,j)^2 / sigma)
```

**雷达调制变体（可选）。** 进一步用候选框的雷达点支持度 `s_j` 调节衰减强度：

```text
sigma_eff = sigma * (1 + beta * s_j)      # beta=0 退化为标准 Soft-NMS（headline 配置）
score_j   = score_j * exp(-IoU(i,j)^2 / sigma_eff)
```

当框内有雷达点支持时 `sigma_eff` 更大、衰减更轻，物理回波支持的候选更不易被删除。该变体只调整分数、不移动框坐标，因此不损害严格定位。消融显示：标准 Soft-NMS（`beta=0`）给出最高 `mAP50-95`，雷达调制（`beta>0`）对总 mAP 近似中性，但在 `AR50-95` 与 `AP75` 上更优，适合“宁可多报不可漏报”的水面安全场景。

### 效果

以标准多尺度 Soft-NMS 为 headline 配置，相比创新点二 `mAP50-95 +1.455`（`50.552 → 52.007`）、`AP75 +2.005`、`AR50-95 +4.774`、弱光 `mAP_di +1.360`、小目标 `mAP_sm +1.721`。其中 `AR50-95` 提升最大，说明双尺度候选补充与 Soft-NMS 有效减少了漏检；`AP75` 同步提升，说明保留下来的候选并非低质量框。雷达调制变体在此基础上进一步将 `AR50-95` 提到 `60.282`、`AP75` 提到 `55.964`。代价是推理时间增加（两次尺度前向），因此建议作为高精度推理模式；默认部署使用创新点二的单次前向权重。

## 理论形式化（论文写作用）

本节给出三项方法的统一数学表述，便于论文中以公式呈现。记检测头在所有 anchor 上的输出为预测框 $\hat{b}_i$、objectness logit $o_i$、类别 logit $\mathbf{c}_i$，$i \in \{1,\dots,N\}$。正样本集合（与某真值框匹配的 anchor）记为 $\mathcal{P}$。

### 1. Radar-Prior Quality-Aligned Head

**质量对齐目标。** 原 YOLOX 用硬 objectness 目标 $t_i=\mathbb{1}[i\in\mathcal{P}]$。本文将正样本目标替换为其定位质量（预测框与匹配真值框的 IoU）：

$$
t_i \;=\;
\begin{cases}
\operatorname{IoU}\!\big(\hat{b}_i,\, b_{\pi(i)}^{\mathrm{gt}}\big), & i \in \mathcal{P}\\[2pt]
0, & i \notin \mathcal{P}
\end{cases}
$$

其中 $\pi(i)$ 为标签分配（SimOTA）给出的匹配真值索引。

**Quality Focal Loss。** 以 $p_i=\sigma(o_i)$ 为预测概率，引入聚焦因子 $|t_i-p_i|^{\beta}$（$\beta=2$），放大“分数与质量不一致”的难样本：

$$
\mathcal{L}^{\mathrm{QFL}}_i \;=\; \big|\,t_i-p_i\,\big|^{\beta}\;\cdot\;\mathrm{BCE}\!\big(o_i,\,t_i\big).
$$

**雷达占据先验重加权。** 设雷达回波占据图按 FPN 各尺度自适应池化到检测网格后，anchor $i$ 处的占据指示为 $R_i\in\{0,1\}$。对 objectness 损失做空间重加权：

$$
w_i \;=\; 1 + \lambda\, R_i,\qquad \lambda=0.5,
$$
$$
\mathcal{L}_{\mathrm{obj}} \;=\; \frac{1}{N_{\mathrm{fg}}}\sum_{i=1}^{N} w_i\,\mathcal{L}^{\mathrm{QFL}}_i .
$$

总损失沿用 YOLOX 形式，仅 objectness 项被替换：$\mathcal{L}=\mathcal{L}_{\mathrm{box}}+\mathcal{L}_{\mathrm{obj}}+\mathcal{L}_{\mathrm{cls}}$（分割分支损失另计）。该设计仅改变监督信号与梯度分配，不改动网络结构与推理流程。

### 2. Greedy Radar-Scale Weight Soup

设候选权重集合 $\{\theta_k\}_{k=1}^{K}$（质量对齐模型多个收敛期检查点 + 多尺度微调模型 best），按各自验证指标 $\mathrm{mAP}(\theta_k)$ 降序排列。贪心地构造成分集合 $\mathcal{S}$：

$$
\mathcal{S}\leftarrow\{\theta_{(1)}\};\quad
\text{for } k=2,\dots,K:\;
\mathcal{S}\leftarrow
\begin{cases}
\mathcal{S}\cup\{\theta_{(k)}\}, & \text{if } \mathrm{mAP}\!\Big(\tfrac{1}{|\mathcal{S}|+1}\!\!\sum_{\theta\in\mathcal{S}\cup\{\theta_{(k)}\}}\!\!\theta\Big)\ge \mathrm{mAP}\big(\bar\theta_{\mathcal{S}}\big)\\[4pt]
\mathcal{S}, & \text{otherwise}
\end{cases}
$$

最终权重为成分均值 $\theta^\star=\frac{1}{|\mathcal{S}|}\sum_{\theta\in\mathcal{S}}\theta$。其合理性在于：同结构、同任务但训练轨迹不同的解通常落在损失面同一低损连通盆地内，其线性插值仍为低损解（model soup 假设），故权重平均可在不增加推理成本的前提下逼近集成收益。

### 3. Multi-Scale Soft-NMS Test-Time Refinement（含雷达调制变体）

对图像在尺度集合 $\mathcal{T}=\{320,384\}$ 上分别推理，将检测框统一映射回原图坐标并合并为候选集 $\mathcal{D}$。去重采用 Gaussian Soft-NMS：在当前最高分框 $m$ 下，对其余框 $j$ 连续衰减分数，避免普通 NMS 的硬删除。引入可选的**雷达支持度** $s_j\in[0,1)$（框内雷达点计数经饱和映射）调制衰减带宽：

$$
\sigma^{\mathrm{eff}}_j = \sigma\,(1+\beta_{\mathrm{NMS}}\, s_j),\qquad
\mathrm{score}_j \leftarrow \mathrm{score}_j \cdot \exp\!\Big(-\frac{\operatorname{IoU}(m,j)^2}{\sigma^{\mathrm{eff}}_j}\Big).
$$

取 $\beta_{\mathrm{NMS}}=0$ 即为标准 Soft-NMS（headline 配置，最高 mAP）；取 $\beta_{\mathrm{NMS}}>0$ 时雷达支持度越高、衰减越轻，物理回波支持的重叠候选越不易被抑制——该变体对总 mAP 近似中性但提升 $\mathrm{AR}$ 与 $\mathrm{AP}_{75}$。该过程只修改置信度、不改动框坐标，因此不损害严格定位指标。

> 说明：上述 $\beta$ 在创新点一（QFL 聚焦指数）与创新点三（Soft-NMS 雷达调制系数）中为不同超参，论文中应分别记为 $\beta_{\mathrm{QFL}}$ 与 $\beta_{\mathrm{NMS}}$ 以免混淆。

## 论文表述建议

可将三项方法组织为一个递进框架：

```text
Baseline
  -> Radar-Prior Quality-Aligned Head           (训练监督)
  -> Greedy Radar-Scale Weight Soup              (权重融合)
  -> Multi-Scale Soft-NMS Test-Time Refinement   (测试时精炼，含雷达调制变体)
```

推荐写法：
1. **Radar-Prior Quality-Aligned Head**：将 objectness 与定位 IoU 对齐（QFL），并用雷达回波占据图重加权监督，使模型在弱视觉证据区域获得更有效的训练信号。
2. **Greedy Radar-Scale Weight Soup**：在权重空间贪心融合质量对齐模型与多尺度微调模型，得到无需集成、无额外推理成本的更优单一权重。
3. **Multi-Scale Soft-NMS Test-Time Refinement**：测试阶段聚合双尺度候选并以 Soft-NMS 缓解过度抑制；进一步提供雷达支持度调制变体，在召回与高 IoU 定位维度优化，适配水面安全场景。

最终结论：三项方法分别从训练监督、权重融合与测试时精炼三个层面增强 ASY-VRNet。在相同评估协议下，将 `mAP50-95` 从 `42.570` 提升到 `52.007`，并带来 `AP75 +11.951`、`AR50-95 +12.935`、弱光 `+9.620`、小目标 `+9.959` 的提升，说明方法对水面复杂场景的定位质量、召回能力与困难样本检测均有贡献。
